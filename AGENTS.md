# SecondRoute contributor instructions

Use desktop browser workflows only. Do not add a phone application.
Do not use em dash characters in authored project files.
Read relevant local Next.js guides under node_modules/next/dist/docs before changes.
Keep demo role switching isolated to demo mode and preserve recipient-confirmed recovery accounting.
Run typecheck, lint, tests, and the production build for substantive changes.
Never commit .data, private signing keys, uploads, or environment secrets.
